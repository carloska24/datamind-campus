# Direção visual

Consulta: 03/10/2026.

- Brilliant — https://brilliant.org/data/ — referência de abordagem: conceitos visuais, exploração e pergunta antes do feedback.
- DataCamp — https://www.datacamp.com/ — referência de organização: percurso, módulos e prática com dados.

A tradução visual é própria: fundo claro, navegação lateral, hero violeta, mint para aplicação industrial e peach para reflexão. Hierarquia de conteúdo, área de leitura central e painel de anotações lateral. As cores têm papéis consistentes. O visual não copia marca, identidade ou assets dessas plataformas.

Desenhos vetoriais próprios em React/SVG: fábrica conectada, estação de montagem, placa, painel de dados e miniaturas de módulos. São elementos do código, escaláveis e editáveis. Ícones: Lucide, licença ISC (atribuição no arquivo THIRD_PARTY_NOTICES).

A fonte usa Aptos/Inter/Segoe UI quando instaladas e fontes do sistema como alternativa; sem download obrigatório. Animações suaves respeitam `prefers-reduced-motion`. Estados incluem seleção, progresso, vazio, erro, geração e pausa. A versão móvel oferece navegação em gaveta.
